# celestial-bodies-DB
A PostgreSQL database designed for the freeCodeCamp Relational Database certification. This project features a complex schema representing the universe, including galaxies, stars, planets, and moons, utilizing primary/foreign keys, unique constraints, and diverse SQL data types.
# Celestial Bodies Database

This project was built as part of the **freeCodeCamp Relational Database Curriculum**. It demonstrates proficiency in SQL schema design, data normalization, and relational mapping.

## Technologies Used
* **PostgreSQL**
* **SQL**
* **Git**

## Features
* 5+ related tables (`galaxy`, `star`, `planet`, `moon`, and more).
* Automated primary keys and structured foreign key relationships.
* Strict data integrity with `NOT NULL` and `UNIQUE` constraints.
